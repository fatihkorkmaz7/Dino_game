# Dino Game

Dino Game, Unity ve C# kullanılarak geliştirilen bir 2D masaüstü oyunudur. Google Chrome’daki dinozor oyununa benzer şekilde, oyuncu dinozoru kontrol ederek engellerin üzerinden zıplar ve en yüksek skoru elde etmeye çalışır. Basit ve akıcı oynanışıyla refleksleri test eden eğlenceli bir deneyim sunar.

## Özellikler
- 2D grafikler
- Basit ve akıcı oynanış
- Yüksek skor takibi
- Unity ve C# kullanılarak geliştirilmiştir

## Kurulum
Bu oyunu bilgisayarınıza kurmak için aşağıdaki adımları izleyin:
1. [Unity](https://unity.com/) oyun motorunu indirin ve kurun.
2. Bu depoyu klonlayın:
    ```sh
    git clone https://github.com/fatihkorkmaz7/Dino_Game.git
    ```
3. Unity ile projeyi açın ve çalıştırın.

## Nasıl Oynanır
- Dinozoru kontrol etmek için klavyenizdeki boşluk tuşunu kullanın.
- Engellerin üzerinden zıplayarak en yüksek skoru elde etmeye çalışın.
